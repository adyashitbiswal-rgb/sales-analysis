# Project 1 — Sales Data Analysis

## Goal
Explore sales transactions and identify revenue patterns by month, product, and region.

## Stack
Python, Pandas, Matplotlib.

## Run
```bash
pip install -r requirements.txt
python analyze_sales.py
```

## Outputs
The script creates `outputs/` containing summary CSV files and PNG charts.

## Questions to answer in your own analysis
- Which product generated the most revenue?
- Which region generated the least revenue?
- Does monthly revenue show a trend?
- What additional metrics would help a sales manager?

**Dataset note:** `sales.csv` is generated sample data for practice, not real company data.
